User Guide

How to download, extract, and run your application successfully.

1. Downloading the App

Go back to the home page and click the download button to get the .zip package containing your application files.

2. Extracting the Package

  1. Locate the downloaded .zip file in your computer's Downloads folder.
  2. Right-click the zip file and select Extract All... (or use your preferred extraction software).
  3. Choose a destination folder where you want the app to live.

3. Running the Application

  1. Open the extracted application folder.
  2. Find the main application executable from (ominisignal- folder) -> OminiSignal-v1.exe.
  3. Double-click it to launch the app interface instantly.
